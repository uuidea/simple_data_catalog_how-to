# Data management for data publishers, a how-to using simple_data_catalog

Repo to manage/host documentation for endusers of the [simple_data_catalog](https://github.com/uuidea/simple_data_catalog) and [simple_data_catalog_model](https://github.com/uuidea/simple_data_catalog_model). with an emphasis on generic metadata management for data cataloging (based on [DCAT](https://www.w3.org/TR/vocab-dcat-3/),) data lineage (based on [prov-](https://www.w3.org/TR/vocab-dcat-3/)), data quality (based on the [Data Quality Vocabulary](https://www.w3.org/TR/vocab-dqv/)) and data policy (based on [the open digital rights language (odrl)](https://www.w3.org/TR/odrl-model/)).

The goal of the documentation  is to both train people in the basics of (meta) data management and the is of the framework.
