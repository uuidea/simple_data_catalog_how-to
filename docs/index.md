# Data Management for Data Publishers

*A comprehensive how-to guide using simple_data_catalog*

## Overview

Welcome to the complete guide for data publishers, metadata managers, and data stewards who want to create and manage data catalogs using the **simple_data_catalog** framework. This documentation provides practical guidance for implementing standards-based data cataloging with an emphasis on:

- **Data Catalog Metadata** - Based on [DCAT 3](https://www.w3.org/TR/vocab-dcat-3/) for describing datasets and data services
- **Data Lineage** - Based on [PROV-O](https://www.w3.org/TR/prov-o/) for tracking data provenance  
- **Data Quality** - Based on [DQV](https://www.w3.org/TR/vocab-dqv/) for measuring data quality metrics
- **Data Policy** - Based on [ODRL 2.2](https://www.w3.org/TR/odrl-model/) for expressing usage rights
